Zadanie 25. Adapter – stary system płatności
--------------------------------------------------------------
Sklep internetowy korzysta z interfejsu:

  interface Platnosc {
      boolean zaplac(double kwotaPLN);
      String status();
  }

Firma ma też dwie gotowe klasy, których NIE WOLNO modyfikować.
Przepisz je do projektu tak, jak są:

  class StaryTerminal {
      // zwraca kod: 0 = OK, 1 = odrzucono, 2 = błąd połączenia
      public int wykonajTransakcje(long kwotaWGroszach, String waluta) {
          if (kwotaWGroszach <= 0) return 1;
          if (Math.random() < 0.1) return 2;
          System.out.println("Terminal: obciążono " + kwotaWGroszach + " gr " + waluta);
          return 0;
      }
  }

  class ForeignPayGateway {
      // zwraca true, jeśli płatność się udała
      public boolean pay(double amountEUR) {
          if (amountEUR > 1000) return false;
          System.out.println("Gateway: paid " + amountEUR + " EUR");
          return true;
      }
  }

Napisz adaptery StaryTerminalAdapter i ForeignPayAdapter
implementujące Platnosc:
- StaryTerminalAdapter – zamiana złotówek na grosze, kody 0/1/2
  zamienione na czytelny status ("OK", "Odrzucono", "Błąd połączenia"),
- ForeignPayAdapter – przeliczenie PLN na EUR po stałym kursie
  (np. 1 EUR = 4.30 PLN), status "OK" / "Odrzucono".

Klasa Sklep przyjmuje dowolną Platnosc i realizuje zamówienie –
nie może wiedzieć, z którym systemem rozmawia.

  Sklep sklep = new Sklep(new ForeignPayAdapter(new ForeignPayGateway()));
  sklep.zamow("Słuchawki", 249.99);

  interface JednostkaOrganizacyjna {
      String nazwa();
      double kosztPensji();
      int liczbaOsob();
      void podwyzka(double procent);
      void wypiszStrukture(int poziom);
  }

- Pracownik – liść (imię, stanowisko, pensja),
- Dzial – kompozyt: nazwa, kierownik (obiekt Pracownik – liczy się
  do osób i kosztów działu) oraz ArrayList<JednostkaOrganizacyjna>
  podjednostek (pracownicy i inne działy).

Zbuduj firmę – korzeniem jest dział "Firma XYZ", w nim:
IT (z poddziałami Backend i Frontend), Sprzedaż, HR.

Funkcje:
- łączny koszt pensji całej firmy i dowolnego działu,
- liczba osób w dziale (z poddziałami),
- podwyzka(procent) wywołana na dziale – działa rekurencyjnie
  na wszystkich pracowników w środku,
- BONUS: najlepiej opłacany pracownik w dziale.

  Firma XYZ (12 osób, 98 400 zł)
    IT (6 osób, 56 000 zł)
      Backend (3 osoby, 29 000 zł)
        Jan Kowalski – senior dev – 12 000 zł
        ...

Zadanie 29. Obserwator – stacja pogodowa
--------------------------------------------------------------
Interfejsy:

  interface Obserwator { void aktualizuj(Pomiar p); }
  interface Obserwowany {
      void dodajObserwatora(Obserwator o);
      void usunObserwatora(Obserwator o);
      void powiadom();
  }

StacjaPogodowa (Obserwowany) przechowuje bieżący Pomiar
(temperatura, wilgotność, ciśnienie) i ArrayList obserwatorów.
Metoda nowyPomiar(...) zapisuje dane i powiadamia obserwatorów.

Obserwatorzy:
- WyswietlaczBiezacy – wypisuje aktualny pomiar,
- WyswietlaczStatystyk – pamięta historię, wypisuje min/max/średnią,
- AlarmMrozu – reaguje tylko, gdy temperatura < 0,
- Prognoza – na podstawie zmian ciśnienia: "poprawa", "pogorszenie",
  "bez zmian".

Symuluj 10 pomiarów (losowych lub z tablicy). W połowie symulacji
odłącz jeden wyświetlacz i pokaż, że przestaje dostawać dane.

--------------------------------------------------------------
Zadanie 30. Obserwator – kanał YouTube
--------------------------------------------------------------
Klasa Kanal (nazwa, ArrayList subskrybentów, ArrayList filmów).
Klasa Film (tytuł, kategoria).
Interfejs Subskrybent: void powiadomienie(Kanal k, Film f).

Rodzaje subskrybentów:
- Widz – wypisuje "Ania: nowy film na kanale X: <tytuł>",
- WidzZFiltrem – reaguje tylko na filmy z wybranej kategorii
  (np. tylko "programowanie"),
- Statystyki – HashMap<String, Integer>: ile filmów opublikował
  każdy kanał.

Wymagania:
- subskrybent może obserwować wiele kanałów,
- subskrypcja / anulowanie w dowolnym momencie,
- nie można zasubskrybować tego samego kanału dwa razy
  (sprawdź contains() przed dodaniem do listy),
- metoda opublikuj(Film f) dodaje film i powiadamia subskrybentów.

  Kanal java = new Kanal("JavaPL");
  Widz ania = new Widz("Ania");
  java.subskrybuj(ania);
  java.opublikuj(new Film("Wątki w Javie", "programowanie"));
  // Ania: nowy film na kanale JavaPL: Wątki w Javie

BONUS: Kanal jest jednocześnie obserwatorem innego kanału
(np. kanał "Najlepsze z Javy" automatycznie udostępnia filmy
z kategorii "programowanie" z kanału JavaPL). Uważaj na pętle!
